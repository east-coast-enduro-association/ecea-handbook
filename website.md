# Website (ecea.org)

Our public website is where we share information with the community.

## Overview

- **URL**: [ecea.org](https://ecea.org) (TODO: confirm URL)
- **Hosted on**: Netlify (automatic deployment)
- **Built with**: Astro (static site generator) + Tina CMS (content editor)

## Who Manages the Website?

The **Webmaster** (see [Contacts](contacts.md)) handles:
- Content updates
- Technical maintenance
- Adding new pages

## Requesting Changes

If you need something updated on the website:

1. Post in the **#website** Zulip stream
2. Include:
   - What page needs updating
   - What the change should be
   - Any images or documents to include

## How Content Gets Updated

For those curious about the process:

1. Webmaster logs into Tina CMS (a visual editor)
2. Makes the changes
3. Saves → automatically publishes to the live site

For larger changes, the webmaster may edit code directly in the [ecea-ui repository](https://github.com/ECEA/ecea-ui).

## Images and Media

Website images are stored in Cloudflare R2 (not on the website itself). See [Cloudflare R2](cloudflare-r2.md) for details.
